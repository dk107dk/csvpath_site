# Validating JSON

CsvPath Framework validation JSON in a few different ways, depending on your use case.

* You chose standalone validation or full data preboarding workflows
* Your validation is on "live" objects or on files on disk
* You can validate:&#x20;
  * [JSONL](validating-jsonl-with-jsonpath.md)&#x20;
  * [JSON documents](validating-json-documents.md)
  * [JSON objects](validating-json-objects.md)
  * JSON documents in an array
  * JSON embedded within CSV headers
  * You can validate JSON documents using one or more JSONPath rules
  * You can validate JSONL headers using JSONPath rules

Moreover, if you are doing dynamic runs on live objects, you can choose to register your data or just run the validation without capturing the input.

A lot of options and combinations, to be sure! But your use case will will make the choices obvious and easy. And these pages give you examples to get you started.
